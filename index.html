Install in 10 Seconds

Whether you install the standard GNOME Extension .zip bundle or run the standalone Rust installer, Kelp configures the exact same out-of-the-box experience.

Option 1: GNOME Extension .zip (No compiler needed)

Download kelp@ubermetroid.github.io.shell-extension.zip from the latest release and install with GNOME's built-in tool:

gnome-extensions install --force \
  kelp@ubermetroid.github.io.shell-extension.zip
gnome-extensions enable kelp@ubermetroid.github.io

Option 2: Standalone kelp CLI Installer

Installs the extension, compiles schemas, and automatically clears GNOME's conflicting default Ctrl + Super + Left/Right shortcuts:

chmod +x kelp-linux-x86_64
./kelp-linux-x86_64

# Or build from source with Rust:
cargo install --path . --root ~/.local && kelp

Top-Bar Menu Controls

Click the Kelp icon in the GNOME top panel to toggle behavior anytime without opening settings.

Menu Item Default What It Does
Tile Windows On Enable or disable automatic BSP window tiling globally.
Keyboard Shortcuts On Dynamically enable or disable all Kelp keyboard shortcuts (ideal for full-screen games, VMs, or remote desktop apps).
Focus Follows Mouse Off (Click) Switch GNOME's window focus mode between Click-to-Focus (click) and Focus-Follows-Mouse (sloppy).
Retile Workspace Action Immediately recalculate and snap all tiled windows on the current workspace into alignment.
Floating Window Exceptions Action Pick any open window or app to always float (Steam, dialogs, PiP, caligula, btm, and macchina float by default).
Show Active Hint On Show or hide the 2px red (rgb(255,0,0)) border around the focused window.
Smart Gaps Off Hide outer gaps when only a single tiled window is open on a workspace.
Border Radius & Gaps 2 px Adjust active border corner radius (0–30 px) and window gaps (0–64 px) live.

Keyboard Shortcuts

Both Vim keys (H J K L) and Arrow keys work out of the box.

Shortcut Action
Super + Arrow or Super + H/J/K/L Focus window Left / Down / Up / Right
Ctrl + Super + Arrow or H/J/K/L Move tiled window Left / Down / Up / Right (reshuffles layout)
Super + Shift + Arrow or H/J/K/L Move tiled window Left / Down / Up / Right (reshuffles layout)
Super + O Toggle split orientation (Horizontal / Vertical)
Super + S Toggle tabbed window stacking on the focused window
Super + G Toggle floating mode for the focused window
Super + Y Toggle automatic tiling on / off globally
Super + Enter Enter interactive adjustment mode (Shift + Directions to resize, Enter to apply, Esc to cancel)

Why Trust Kelp?

GNOME Shell extensions run inside your Wayland compositor process. Kelp is engineered so you can verify everything it does.

Zero Daemons or Subprocesses

Legacy X11 utilities (xprop), background launcher daemons, and DBus services have been completely removed. Everything uses native Mutter window manager APIs.

Zero Third-Party Dependencies

The GNOME extension uses zero npm packages, and the Rust installer uses only the Rust standard library (0 external crates in Cargo.lock). No network access or telemetry.

Clean Disable & Lock Screen

Disabling the extension or locking your session deterministically removes all registered keyboard shortcuts, border actors, and signal handlers.
